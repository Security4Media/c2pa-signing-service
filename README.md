# C2PA Signing Service Documentation

Public documentation source for Security4Media's C2PA Signing Service.

The generated GitHub Pages site is built from `docs/` with Zensical. The OpenAPI specification at `docs/api/openapi.json` is generated from the private service implementation and synchronized into this repository.

## Roadmap

See the [Roadmap](docs/roadmap/README.md) for the capability areas we expect to document and expand next, including a proposed [MXF reference implementation](docs/roadmap/mxf-reference-implementation.md) that the Security4Media authenticity group could contribute to.
